# Lexi — Dictionary & Word Lookup App

## Requirements covered
- Free Dictionary API
- JavaScript Fetch API
- Search input + search button
- Debounced live search
- Multiple meanings
- Multiple definitions under each part of speech
- Phonetics
- Pronunciation audio
- Example sentences
- Synonyms when supplied by API
- Word-not-found/error handling
- Responsive animated 3D/glass UI

## Tech
HTML5, CSS3, JavaScript, Fetch API

## Run
Open `index.html` with internet access.

## Interview Questions
1. How would you display multiple meanings for one word?
2. How would you handle a word that isn't found?
3. How would you play an audio pronunciation from a URL?
